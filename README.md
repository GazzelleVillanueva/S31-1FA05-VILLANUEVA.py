                                                  Distance Calculator
                                          By: Gazzelle Nathalia P. Villanueva          
                              This Python program calculates the distance between two points.
                                                   Input Needed:
                                        x1: X-coordinate of the first point
                                        y1: Y-coordinate of the first point
                                        x2: X-coordinate of the second point
                                        y2: Y-coordinate of the second point

                                          How to run the code:
                             1. Open your code editor.
                             2. Make sure Python is installed in your computer.
                             3. Open your terminal or command prompt.
                             4. Navigate to the directory containing the project file.
                             5. Run the program.

                                          Sample Ouput:
                             Enter x1: 1
                             Enter y1: 2
                             Enter x2: 4
                             Enter y2: 6

                            The distance between the two points is: 5.00
